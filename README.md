# SHEIN 选品定价台

输入一条 1688 商品链接 → 自动读商品/价格/规格 → 生成差异化变种规格并算好定价 → 导出上架表。
本地跑、局域网可访问、开机自启；**价格一律由本地引擎算**（可选让 DeepSeek 参与"排变种"）。

## 它解决什么

选品时最烦的两件事：页面上的规格写法千奇百怪（多级规格、组合值、价只挂最后一维、一维多值且每值自带价……），
以及"这一堆变种到底该怎么定价"。这个工具把这两件事都收敛成一条链路：

```
1688 链接 → 抓取（真实浏览器，人工过验证）→ 解析计价要素 → 生成变种规格 → 套定价口径 → CSV 上架表
```

## 定价口径（与「跨境定价计算器」一致）

| 项 | 规则 |
|---|---|
| 折扣叠加 | 还价 20% 与折扣 15% **乘性**叠加，K =(1−0.2)×(1−0.15)= 0.68（可切相加） |
| 成本 | **按各规格自己的标价**（打包阶梯：单片 2.12 / 5片装 11.5 / 10片装 23 时，每行用自己那一档） |
| 运费 | 成本的 10% |
| 利润 | 到手价 − 拿货成本 − 运费（口径可选 ÷到手价 / ÷标价 / 成本倍数） |
| 定价 | 总成本 ÷ [K ×(1−毛利率)]，毛利率默认 33% |
| 欧元价 | 定价 ÷ 7.8 |
| 低价兜底 | 任一规格定价 < ¥3 → 全部规格统一 +¥3 |

## 变种规格怎么生成

- **列**来自页面真实规格维度（父规格 / 子规格，组合值如`【英文版.欧规】紫色全自动32mm`会拆成两列，不交叉生成页面没有的组合）。
- **行**默认按引擎规则：**页面有几个规格值就几行**，名字就是页面值原文 —— 引擎不编任何包装单位或组合
  （不写「双支装 / 九支装 / 便携收纳盒」这类词，用户明确要求过）。
  要打包、多件、混搭、带配件，只能让 **DeepSeek 档**按真实数据自己判断；它若造了数据里没有的单位/配件词，
  那一栏会被打回、回落成规格值原文。
- **可选 DeepSeek 档**：让模型"思考"该排哪些组合、件数，以及**中英文两个变种名**。它**只排计划**——
  不算钱（价格/成本仍由引擎算）、不许编造页面上没有的规格值、不许静默丢规格（漏了要么补要么写明不上架的理由），
  校验不过就回落到引擎规则。详见 `docs/局域网部署.md` §9。

## 跑起来

```bash
# 依赖：Node（自带 playwright 的那个 Hermes node）+ Python 3
python server.py            # 默认 0.0.0.0:8901
# 打开 http://127.0.0.1:8901/
```

Windows 上还有一组脚本：`serve.cmd`（前台跑）、`service.cmd`、`install-autostart.cmd`（开机自启）、
`stop-service.cmd`、`verify-autostart.cmd`、`allow-lan-firewall.cmd`（放行 8901）、
`import-chrome-login.cmd`（导入自己 Chrome 的 1688 登录态，避免每次过验证）。

## 测试

```bash
node test_parse.cjs   # 解析层（真实页面文本 fixtures）
node test_app.cjs     # 变种生成 + 定价引擎
node test_page.cjs    # 用 jsdom 真跑 index.html 的交互
node test_ai.cjs      # DeepSeek 计划的硬校验 / 回落 / 不许碰钱
```

全部用例必须看到收尾的「全部通过」。

## 目录

| 文件 | 作用 |
|---|---|
| `parse-1688.js` | 页面文本 → 商品/价格/规格（含重量、箱装、档位过滤） |
| `app.js` | 变种生成 + 定价引擎（口径、低价兜底、SKU、英文名） |
| `index.html` | 单页界面（参数联动、表格、CSV/公式导出） |
| `server.py` | 静态服务 + 抓取任务 + `/api/ai-plan` |
| `fetch-1688.cjs` | 走 CDP 的真实浏览器抓取（人工过验证，永不并发） |
| `tool-browser.cjs` | 常驻工具浏览器（可切"用你自己的 Chrome"） |
| `ai-plan.cjs` | DeepSeek 排变种（提示词、硬校验、回落） |
| `fixtures/` | 真实抓取下来的页面文本，供解析回归测试 |
| `docs/局域网部署.md` | 部署、机制、故障排查、AI 档说明 |

## ⚠️ 安全

`.ai.json`（模型密钥）、`.chrome-cookies.json`、`.chrome-profile/` 一律在 `.gitignore` 里，**不要提交**。
密钥只在服务端使用；页面与接口返回里都不会出现密钥。
